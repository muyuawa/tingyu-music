# 听屿 · Tingyu Music

Windows 本地离线音乐播放器，支持专辑取色动态背景、液态玻璃控制条、同步歌词和 WASAPI / ASIO 音频输出。

[下载最新版本](https://github.com/muyuawa/tingyu-music/releases/latest)

## 使用

- 支持 Windows 10 2004 及以上的 64 位系统。
- 安装版运行 MSI；便携版完整解压 ZIP 后运行 `Muyu.App.exe`。
- 添加本地音乐文件或文件夹即可播放，也支持拖入文件。
- 更新前从托盘退出播放器。更新保留数据；卸载会清除应用数据，不删除原始歌曲。

第三方许可见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)，歌词扩展见 [EXTENSIONS.md](EXTENSIONS.md)。
